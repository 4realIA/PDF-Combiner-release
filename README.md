# Installing PDF Combiner on a Mac

PDF Combiner puts PDFs and photos together into one file, in the order you choose. It works on Macs with Apple silicon (M1 or newer).

## Install (one time)

1. Go to **https://github.com/4realIA/PDF-Combiner-release/releases/latest**.
2. Under **Assets**, click the file ending in **`.dmg`** to download it.
3. Open the downloaded file. In the window that appears, drag **PDF Combiner** onto the **Applications** folder.
4. Open **Applications** and double-click **PDF Combiner**.

From version 0.6.1 the app is signed with Andy's Apple Developer ID and checked by Apple, so it opens straight away.

**Older copies only (0.6.0 and earlier):** if the Mac says "Apple could not verify…", click **Done**, open **System Settings → Privacy & Security**, click **Open Anyway** next to **"PDF Combiner" was blocked**, then **Open Anyway** again and type your Mac password. After that it opens normally, and you can keep it in the Dock (right-click its icon → Options → Keep in Dock).

## Updates

Nothing to do. PDF Combiner checks for a new version by itself and installs it in the background. The new version is used the next time you open the app. You'll see a small "Updated to …" note at the bottom of the window when that's happened.

## Using it

1. Click **Add files** (or drag PDFs and photos onto the window). Each photo becomes a page.
2. Drag pages into the order you want: a photo can go between pages of a worksheet. Each page also has buttons to move it, turn it, or delete it. The list on the left moves whole files. **Undo** (⌘Z) puts things back.
3. Leave **Make all pages Letter size** ticked so every page comes out 8.5 × 11.
   If the site you're uploading to has a size limit, pick it under **Keep under** (for example 5 MB). Photos are made smaller just enough to fit.
4. Click **Combine and save**, choose a name, and save. **Show in Finder** takes you to the new file.
